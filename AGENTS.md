# fivecentplots — Agent Reference

The full agent-oriented kwarg reference for this library lives at:

**[`src/fivecentplots/AGENTS.md`](./src/fivecentplots/AGENTS.md)**

That file is the canonical, single source of truth (it also ships inside the installed
package, so `pip install fivecentplots` alone is enough to have it available locally at
`site-packages/fivecentplots/AGENTS.md`). This root-level file is intentionally just a
pointer to avoid maintaining two copies.

If you are an agent with repo access: open the file linked above.
If you only have a raw URL: fetch
`https://raw.githubusercontent.com/endangeredoxen/fivecentplots/main/src/fivecentplots/AGENTS.md`
directly instead of this one.
